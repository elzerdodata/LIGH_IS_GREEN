# Light is Green v1.0.6

> A clean, immersive redesign of the Cloud Library grid.

## 🌟 What's New

* **Clean Grid Interface (5x2)**: The game library has been redesigned to feature larger, cleaner cover art.
* **No Text Clutter**: Removed the game titles from underneath each cover for a sleeker look. The full title is still prominently displayed in the top panel when a game is focused.
* **Pure Artwork**: Dark bands and ambient padding around covers have been removed. The UI now prioritizes the native square Xbox BoxArt for a premium, edge-to-edge feel.
* **Fresh Cache**: The image cache system has been updated. It will cleanly fetch the new square covers instead of reusing the old vertical ones.
* **Full Navigation Kept**: Despite the visual overhaul, all core features—sidebar navigation, touch controls, focus memory, and pagination—remain fully intact.

# Light is Green v1.0.6 (Español)

> Un rediseño visual limpio e inmersivo para la biblioteca de la nube.

## 🌟 Novedades

* **Nueva Grilla Limpia (5x2)**: La biblioteca de juegos ha sido rediseñada para mostrar carátulas mucho más grandes y detalladas.
* **Sin Texto Inferior**: Se eliminaron los nombres debajo de cada juego para un aspecto más elegante. El título completo de cada juego continúa apareciendo claramente en el panel superior al seleccionarlo.
* **Arte Puro**: Se han eliminado las bandas oscuras y el relleno ambiental alrededor de las carátulas. Ahora el sistema prioriza el BoxArt cuadrado nativo de Xbox para una experiencia premium y sin bordes.
* **Nueva Caché**: El sistema de caché de imágenes fue actualizado. Ya no reutilizará las antiguas portadas verticales y descargará limpiamente las nuevas versiones cuadradas.
* **Navegación Intacta**: A pesar del enorme cambio visual, se ha conservado a la perfección la navegación lateral, los controles táctiles, el sistema de foco y la paginación.
