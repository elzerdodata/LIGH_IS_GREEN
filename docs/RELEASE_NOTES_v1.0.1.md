# ZERODROID v1.0.1 — Stable initial release / Primer lanzamiento estable

`ZERODROID_v1.0.1.nro` is the first complete stable release of ZERODROID, the
unofficial open-source Boosteroid client for Nintendo Switch homebrew.

## Espanol

### Destacados

- Biblioteca completa paginada: **Mis juegos**, **Catalogo**, **Favoritos** y
  **Recientes**, con busqueda nativa y favoritos persistentes.
- Inicio de sesion QR, seleccion de idioma, servidor preferido, regiones
  lejanas y disposicion de botones Nintendo/Xbox.
- Video H.264 nativo, audio Opus, entrada completa del mando y recuperacion de
  streaming para sesiones de Boosteroid.
- Centro de control durante el stream con Xbox Guide, Steam Menu, ALT+TAB,
  informacion de teclado, raton, reconexion, graficos y retorno al juego.
- Navegacion por mando y tactil, medidor de ping, portadas verticales sin
  estiramiento ni barras laterales, y textos ajustados a cada panel.

### Instalacion

1. Descarga `ZERODROID_v1.0.1.nro`.
2. Copialo a `sdmc:/switch/ZERODROID/ZERODROID.nro`.
3. Abre Homebrew Menu mediante title takeover: mantén **R** al iniciar un juego
   instalado. No uses Album/applet mode; no dispone de memoria suficiente para
   streaming.

## English

### Highlights

- Complete paginated library: **My Games**, **Catalog**, **Favorites** and
  **Recent**, with native search and persistent favorites.
- QR login, language selection, preferred server, distant regions and
  Nintendo/Xbox button layout.
- Native H.264 video, Opus audio, complete controller input and streaming
  recovery for Boosteroid sessions.
- In-stream Control Center with Xbox Guide, Steam Menu, ALT+TAB, keyboard
  information, mouse, reconnect, graphics and return-to-game actions.
- Controller and touch navigation, a ping meter, vertical cover artwork with
  no stretching or side bars, and text sized to its panels.

### Installation

1. Download `ZERODROID_v1.0.1.nro`.
2. Copy it to `sdmc:/switch/ZERODROID/ZERODROID.nro`.
3. Launch Homebrew Menu through title takeover: hold **R** while opening an
   installed game. Do not use Album/applet mode; it does not provide enough
   memory for streaming.
