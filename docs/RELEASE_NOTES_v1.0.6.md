# Light is Green v1.0.6

## Español

- Nueva biblioteca **5 × 2**, con diez carátulas cuadradas considerablemente más
  grandes por página.
- La aplicación ahora prioriza el `BoxArt` cuadrado nativo que Xbox devuelve
  para cada juego, en lugar del `Poster` vertical.
- Las tarjetas muestran solamente arte limpio: sin título duplicado, franjas
  oscuras, relleno ambiental ni capas encima de la imagen. El nombre completo
  permanece en el panel superior al seleccionar un juego.
- La animación de foco, navegación lateral, control táctil, paginación y pantalla
  de detalle se conservaron.
- El esqueleto de carga reproduce las nuevas proporciones para evitar saltos de
  interfaz mientras llegan las carátulas.

## English

- New **5 × 2** library layout with ten considerably larger square covers per
  page.
- The app now prioritizes the native square `BoxArt` supplied by Xbox instead
  of the vertical `Poster` asset.
- Tiles contain clean artwork only: no duplicated title, dark side bands,
  ambient filler, or image overlays. The full title remains available in the
  upper selection panel.
- Focus animation, sidebar navigation, touch controls, pagination, and the game
  detail screen are preserved.
- The loading skeleton matches the new card proportions to prevent layout
  shifts while artwork is loading.
