# Light is Green v1.0.1 UI Preview

Experimental visual build kept separate from v1.0.0. It changes no Xbox
authentication, catalog, streaming, network, or decoder code.

- Remote Play now uses the Light is Green mark instead of the generic `YX`
  console-cover fallback and avoids the `Your Xbox` placeholder when no custom
  console name is available.
- The existing 6-by-3, 18-game library is denser: smaller inter-card gaps,
  compact title strips, and a subtle divider that binds each full, un-cropped
  cover to its title.

## Español

Compilación visual experimental y separada de v1.0.0. No cambia el inicio de
sesión de Xbox, catálogo, streaming, red ni decodificación.

- Remote Play usa el icono de Light is Green en lugar de la portada genérica
  `YX`, y evita el texto `Your Xbox` cuando la consola no tiene nombre propio.
- La biblioteca sigue teniendo 18 juegos en una grilla de 6 por 3, pero con
  menos espacio entre tarjetas, títulos más compactos y una separación visual
  suave entre portada completa y título.
