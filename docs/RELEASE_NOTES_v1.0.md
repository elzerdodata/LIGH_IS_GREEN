# Light is Green v1.0.0

## English

The official Light is Green identity release adds an original mark and aurora background, a compact command-deck header, refined emerald focus motion, and a content-first 6 × 3 game library. Game cards retain uncropped artwork; selected, detail, and source-picker titles no longer use fixed-character truncation.

The data directory changes to `sdmc:/switch/light-is-green/`. v1 imports small account/configuration data for a seamless first run without moving, overwriting, or deleting the prior directory. Cover art is not copied because it is cache.

Cloud Launch exposes only engine phase, effective Xbox server region, selected source, and configured quality. It does not show synthetic estimates.

## Español

La versión de identidad oficial de Light is Green incorpora un icono y fondo aurora originales, cabecera compacta tipo consola, foco verde refinado y una biblioteca 6 × 3 centrada en contenido. Las carátulas siguen sin recortarse; los títulos seleccionados, de detalle y del selector de origen ya no usan cortes fijos de caracteres.

La carpeta de datos pasa a `sdmc:/switch/light-is-green/`. v1 importa datos pequeños de cuenta/configuración sin mover, sobrescribir ni borrar la carpeta anterior. Las carátulas no se copian porque son caché.

Cloud Launch sólo muestra fase del motor, región efectiva, origen seleccionado y calidad configurada. No presenta estimaciones inventadas.
