# Light is Green v1.0 visual direction

The native Switch interface uses an original mark, a single 1280 × 720 abstract aurora backdrop, deep translucent surfaces, thin emerald edges, and a subtle animated focus frame. It stays inside the SDL2 renderer and adds no background video, web view, or large static cover library.

The active library remains a 6 × 3 grid because it is the core interaction: eighteen real games stay visible. The selected game gets a compact command deck with its full scrolling title, availability, page count, and existing controls. Game details and Cloud Launch use larger panels but only show data received by the client.

Reference artwork is used only for composition and colour direction. Light is Green ships neither third-party logos nor character/game artwork as static UI assets; game covers come from the authenticated catalogue already used by the client.
